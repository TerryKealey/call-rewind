CRM needs (1) this page on local HTTP preview, (2) Cloudflare WARP, (3) node scripts/crm-proxy.mjs, (4) your Vault API token (the UUID on api_token is the token).

  1. Open local preview (not call-rewind.quick.shopify.io).
  2. Enable Cloudflare WARP.
  3. Terminal: node scripts/crm-proxy.mjs (leave running).
  4. — copy token (or pbcopy < ~/.cache/vault-crm-token).
  5. Paste below → Save & verify.
